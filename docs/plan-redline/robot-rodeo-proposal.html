Why this shape

LeRobot does the robotics; rodeo keeps the notebook.

Every experiment is a small recipe file. rodeo run <recipe> runs LeRobot's own command, then writes a log record, a readable entry and a short clip. Nothing is re-implemented, so LeRobot's docs and community answers apply directly.

What lands, stage by stage

Five stages, each ending with something to watch or read.

  1. A
    Set up and checksteps 1–2

    Install LeRobot, confirm the GPU works, try each simulator natively (WSL2 for any that fail), and build the rodeo runner and experiment log.

    →Afterwards: uv run python scripts/probe.py and uv run rodeo list.
  2. B
    Watch it workstep 3M1: watch the clips

    Pretrained PushT and ALOHA policies, 50 episodes each, with clips and success rates.

    →Afterwards: uv run rodeo run pusht-pretrained-eval.
  3. C
    Train your ownsteps 4–7overnight wait

    A 2-minute smoke run measures your GPU, the training recipe is sized to fit 8 hours, it runs overnight, then your policy is compared with the pretrained one.

    →Afterwards: uv run rodeo compare <own> <pretrained>.
  4. D
    Drive and recordstep 8M2: record demosM3: train + eval

    Recipes for keyboard recording, ACT training on your demos, and evaluation.

    →Afterwards: uv run rodeo run panda-cube-record.
  5. E

Choices I made on your behalf

Defaults worth your eyes. Reference by ID to tweak.

D11–D15 came from the plan review you accepted. Amber = my call.

D1 Pin LeRobot 0.7.0 with the pusht, aloha, training and dataset extras. LeRobot changes fast; a pin keeps your results comparable over weeks. Tweak: track latest instead (upgrades prompted by community-commando's release watch).
D2 A small rodeo CLI with TOML recipes wrapping LeRobot's own commands. Every experiment becomes one repeatable command with a consistent log entry. Tweak: plain PowerShell scripts instead.
D3 Experiment log: append-only JSONL plus a Markdown entry per run with a “What I noticed” section for you. Machine-readable for comparisons, human-readable for learning in public. Tweak: Markdown only.
D4 Clips up to 5 MB go in git; checkpoints and full videos stay in a gitignored outputs folder. The public log can show what happened without committing gigabytes. Tweak: the size limit, or GIFs instead of MP4.
D5 8-hour cap per training run, a checkpoint at least every 45 minutes, steps sized from measured speed. Fits one night; a crash or sleep loses under an hour. Tweak: the cap (e.g. 6 h).
D6 50 episodes per evaluation. Enough for a success rate with a usable confidence interval; minutes per run. Tweak: 20 for speed, 100 for precision.
D7 Diffusion policy for PushT; ACT for your keyboard demos; about 20 demos. Matches the pretrained references; ACT learns from few demonstrations. Tweak: demo count, or try SmolVLA later.
D8 Not in v1: Weights & Biases, Isaac Sim / LeIsaac, LIBERO, reinforcement learning. Online tracking conflicts with local-only; Isaac Sim is heavy for 8 GB; LIBERO is Linux-only; RL is a later topic. Tweak: restore any one.
D9 Buying note due 2026-12-05. Leaves time to order before Christmas shipping cut-offs. Tweak: the date.
D10 Plan lives at docs/plans/master_plan.md. Workspace canonical location. Tweak: none recommended — tooling discovers this path.
D11 WSL2 runtime available to every simulator from Step 2, chosen per simulator by the Step 1 check. ALOHA's physics wrapper is unverified on Windows too, not only the keyboard sim. Tweak: none recommended.
D12 gym-hil declared as the hil extra; the check also imports the recording module. Keeps it through uv sync; catches the placo problem on day one. Tweak: none recommended.
D13 One shared outputs folder (RODEO_OUTPUTS, else the main checkout's outputs/). Build worktrees and your own runs see the same checkpoints. Tweak: put outputs on another drive.
D14 Explainers are tested: 300–900 words, ending with “What to look for”. Makes the learning deliverable a checked part of each step. Tweak: the word range.
D15 rodeo compare lands in Step 7; data loaders drop below 4 workers if RAM peaks over 12 GB. Smaller steps; your laptop has 16 GB RAM. Tweak: the RAM threshold.
